# Бренд: Кодеїда

> Назва — **Кодеїда / Kodeida** (код + «Енеїда» Котляревського). Головний герой — **Еней**, маскот і помічник — **Лис Микита** (Франко).
> Як усе виглядає наживо: [сайт](https://f3an.github.io/kodeida/) і [артбук](https://f3an.github.io/kodeida/artbook.html).

## 1. Ядро

**Головна ідея:** *хитрість перемагає силу.* В алгоритмах це буквально так: розумний прийом (два вказівники, хеш-мапа, DP)
перемагає грубу силу (brute force). Лис Микита — хитрість, Вовк Неситий — перебір.

| | UA | EN |
|---|---|---|
| **Назва** | Кодеїда | Kodeida |
| **Теглайн** | Гра, де код рухає героя. | A game where your code moves the hero. |
| **Слоган** | Перехитри задачу. / Brute force — для вовків. | Outfox the problem. / Brute force is for wolves. |
| **Обіцянка** | Вчимо прийомів, а не відповідей. | We teach techniques, not answers. |

**Чому «Кодеїда»:** у слові одразу код, квест і Україна. «Енеїда» — мандрівка світ за світом і початок нової української
літератури; англійською *Kodeida* звучить майже як «Code Odyssey». Історія пошуку назви — у [додатку](#додаток-як-обирали-назву).

## 2. Словник: гра ↔ програмування

Усі тексти, UI та контент використовують ці терміни.

| У грі | Що означає |
|---|---|
| **Хитрощі** | Прийоми й патерни (two pointers, sliding window, …) |
| **Книга хитрощів** | Бібліотека прийомів: коли брати, шаблон, складність, живий приклад |
| **Кришталева Писанка, уламки** | Повний набір прийомів; уламок = один прийом, зібраний у світі |
| **Слово ладу** | Код гравця |
| **Підвідні вправи** | Короткі рівні, що готують до прийому |
| **Суд богів** | Запуск тестів |
| **Вовче рішення** | Наївне рішення, O(n²) і гірше |
| **Лисяче рішення** | Оптимальне рішення через прийом |
| **Підказки Сивілли** | 3 рівні: натяк → ідея → псевдокод |
| **Вишиванка Енея** | Прогрес: кожен уламок додає візерунок на сорочку |
| **Пісні** | Розділи кампанії (6 пісень, 16 світів) |
| **Двобій з Турном** | Режим співбесіди: незнайомі задачі без підказок |

### Еней

- «Парубок моторний», козак. **Оселедець закручений у дужку `{`** — головна впізнавана риса і основа логотипа.
- Статний: широкі плечі, руки в боки, шабля при боці; сині шаровари, червоний пояс, червоні чоботи.
- **Вишиванка росте з гравцем**: на старті чиста, кожен уламок додає візерунок (хвилі, два зустрічні ромби, вежа, спіраль,
  дерево життя, барвінок, розетка, соти…). Повністю вишита сорочка — візуальне резюме навичок.
- Варіації: на старті, у жупані, до бою (з піднятою шаблею), на бенкеті.

### Лис Микита

- Образ — з казки Франка **«Фарбований лис»**: упав у діжу з фарбою разом з уламком Писанки.
- **Колір змінюється з кожним світом** (16 фарб, див. [LORE.md §4.1](LORE.md#41-фарбований-микита-колір-за-локацією)); рудим буває лише вдома.
- Поза своїм лісом олюднений чарами Писанки: жилет канцлера, Книга хитрощів, піднятий палець «а ось і хитрість».
- Білий кінчик хвоста блимає, як курсор. Режим експерта — **Остромисл** (різнобарвний, у короні).
- Варіації: олюднений, у рідному лісі (на чотирьох лапах), Остромисл, у полоні.

### Звірі й олюднення

Звірі поза своїм світом олюднені чарами Писанки (ходять на двох ногах, носять одяг). Удома — звичайні звірі:
Цар Лев на ярмарку, мешканці рукавички, вовк до уламка.

## 4. Візуальна ідентичність

**Стиль:** піксель-арт з українськими орнаментами. Без імітації вишивки й стібків.

- **Спрайти малюються кодом** (`site/app.js`): фігури → растр → **Scale2x** (подвоєна роздільність, згладжені діагоналі) →
  світло зліва згори й тінь справа знизу → легка фактура тканини й хутра → **cel-лінії** між різними матеріалами →
  тонкий зовнішній контур 1 HD-піксель. Персонажі можуть бути різного розміру, до спільної сітки не підганяються.
- **Світи** мають власну атмосферу: частинки (жарини, сніг, дощ, світлячки, листя, пил, іскри), світло (промені, сяйво
  лави й горна), туман, колірне тонування і піксельну віньєтку.
- **Орнаменти** — це візерунки уламків Писанки; вони ж іконки в Книзі хитрощів і на вишиванці.

### Логотип

- **Основний:** оселедець Енея `{` + вордмарк «Кодеїда».
- Варіант: крапки над «ї» — два уламки Писанки (червоний і лисячий).
- **Іконка застосунку:** Кришталева Писанка на нічному тлі, ліворуч золотий оселедець-дужка. Розміри 256 / 128 / 64 / 32.

### Рух і звук

Трейлер, ролики до релізів і Reels збирає код у `video/` (Remotion), як і спрайти. Героїв, світи й частинки малює той самий `site/app.js`. Як це виглядає — [артбук, аркуш 10](https://f3an.github.io/kodeida/artbook.html#motion).

- **Ритм.** 150 ударів на хвилину; такт — 1,6 с. Сцени тривають ціле число тактів, склейки падають на долю. Тиха секція перед дропом, удар — на зміні сцени.
- **Музика.** Оригінальний чіптюн у ре гармонічному мінорі (Dm – B♭ – C – A), синтезований скриптом: квадратна хвиля з вібрато, бас октавами, арпеджіо, шумові барабани. Без чужих треків — нічого ліцензувати.
- **Переходи.** Білий спалах на дропі, косий мазок кольору наступної сцени на склейці, легка тряска на ударі. Пікселі не згладжуємо.
- **Текст у кадрі.** Unbounded, слова влітають по одному. Мінімум 84 px для заголовка у вертикальному відео, 120 px — у горизонтальному.
- **Справжня гра в кадрі.** Записи екрана — тільки з реальної гри у 2×, без макетів.
- **Reels 9:16.** Текст поза верхніми 250 px, нижніми 400 px і правим краєм; головне — у центральних 3:4. Перший кадр і є обкладинкою: логотип, версія, герої.

## 6. Голос

Бурлеск Котляревського + іронія Франка. Смішно, по-народному, з переліками та примовками. Сміємося з Юнони й Вовка,
**ніколи не з гравця**. Мови: українська й англійська.

| Ситуація | Приклад |
|---|---|
| Оптимальне рішення · Микита | «Оце по-лисячому! Вовк ще рахує пари, а ми вже пливемо далі.» |
| Працює, але повільно · Микита | «Так розв'язав би Вовк Неситий: O(n²). Пошукай хитрість.» |
| Time Limit · Юнона | «Ха! Мій шторм ще не скінчився, а ти вже видихся.» |
| Помилка · система | «Еней спіткнувся на рядку 12: змінна right не оголошена.» |
| Підказка · Сивілла | «А що, як іти з обох кінців одночасно?» |
| Новий візерунок · система | «На вишиванці Енея з'явилися «два зустрічні ромби».» |
| Новий ранг | «Цар Лев жалує тобі звання Хитруна!» |

## 7. Чого уникаємо

- Копіювання образів з екранізацій (мультфільм «Енеїда» 1991, «Лис Микита» 1990-х, «Мавка», фільм Параджанова).
- Воєнної тематики.
- Спільнослов'янських образів, що асоціюються з російським контентом (Колобок, Їжачок у тумані).
- AI-підказок у самому продукті.

## Додаток: як обирали назву

1. **Робоча назва** — algo-quest (звідси назва локальної теки).
2. Розглядали концепції маскотів: Січ і козак, Чумацький шлях, Вулик, Мольфар, Соняшник, Борщ, Лелека, Писанка;
   обрали **Лиса Микиту** з Франка — хитрість якраз і є суттю продукту.
3. Назви від лиса: *Кмітлис* (кмітливий + лис), *Khytrun*, *lyskod*, *lysground*. Відмовилися: назва не має
   прив'язуватися до маскота.
4. Формула «ім'я + сенс + суфікс» (як Міра.ai): *Дана.code*, *Гордій*, *Ясна*.
5. Тематика «квест + алгоритм + код + Україна» дала **Кодеїду**: «Енеїда» як рамка мандрівки світами, а Микита
   лишився маскотом.
