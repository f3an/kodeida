## 1. Ядро бренду

**Головна ідея:** *хитрість перемагає силу.*
У програмуванні це буквально так: розумний прийом (two pointers, hash map, DP) перемагає
«грубу силу» (brute force). Микита — хитрун, Вовк Неситий — brute force.

| **Теглайн** | Перехитри задачу. | **Outfox the problem.** *(outfox = «перехитрити», і там є fox)* |

### ✅ Назва: Кмітлис / Kmitlys (обрано 2026-10-14)

- **Склад:** *кміт*ливий + *лис*. Одне злите слово (у стилі mono/monobank), без пробілу.
- **Смисл:** кмітливість = вміння швидко побачити хитрий прийом у задачі; лис = Микита.
- **Написання:** `Кмітлис` (UA), `Kmitlys` (EN, за офіційною транслітерацією: і→i, и→y).
  У логотипі та коді — нижній регістр: `kmitlys`.
- **Вимова EN:** «kmeet-lees».
- **Дистрибуція:** десктопний Electron-застосунок без бекенду, тож домен не потрібен.
- **Як звучить разом:** «Кмітлис — перехитри задачу» / «Kmitlys — outfox the problem».
- **Родина назв (за потреби):** kmitlys kit (UI-кіт), розділи — за локаціями лісу (§5).

## 3. Акторський склад

> ⚠️ **Застаріло (2026-10-15):** головний герой тепер **Еней**, Микита — помічник. Актуальний склад — у [`LORE.md`](LORE.md) §4. Нижче — персонажі світу Лиса Микити.

| Персонаж | Роль у грі | Концепт у коді |
|---|---|---|
| **Лис Микита** | Головний герой, яким керує код гравця | Розумне, оптимальне рішення |
| **Вовк Неситий** | Антагоніст-суперник: на початку рівня показує своє рішення і провалюється | **Brute force**, Time Limit Exceeded |
| **Ведмідь Бурмило** | Великий і важкий, займає багато місця | **Memory Limit**, просторова складність |
| **Цар Лев** | Суддя: виносить вердикт, видає ранги | **Тести**, перевірка рішення |
| **Борсук** | Кум і захисник Микити (як у Франка), ментор | **Підказки**, пояснення після рішення |
| **Кіт Мурко** | Цікавий, лізе куди не треба, потрапляє в пастки | **Edge cases**: порожній масив, один елемент, переповнення |
| **Заєць** | Бігає швидко | **Fast pointer** у Fast & Slow |
| **Їжак → ні**, **Черепаха → ні** | — | Slow pointer — **Борсук** (повільний, але дійде) |

**Сценарій типового рівня:**
1. Цар Лев оголошує задачу.
2. Вовк Неситий кидається в лоб: на маленьких тестах проходить, на великих «не встигає» (анімація).
3. Гравець пише код, Микита виконує його у світі.
4. Царський суд: вердикт і порівняння з Вовком (кількість кроків / операцій).
5. Борсук пояснює, *чому* хитрість спрацювала, і сторінка додається в Книгу хитрощів.

## 4. Дизайн героїв: прив'язка до коду

### Еней: головний герой (завжди)

Гравець завжди керує Енеєм, у будь-якому світі.

- **Образ:** «парубок моторний» Котляревського, козак.
- **Оселедець стилізований під `{`.** Це головна впізнавана риса й основа логотипа.
- **Вишиванка з «живим» орнаментом.** Кожен опанований прийом додає на сорочку новий мотив
  (two pointers — два зустрічні ромби, sliding window — рамка, дерево — «дерево життя»).
  Сорочка — візуальне резюме навичок гравця, ним можна поділитися.
- **Емоції** (набір спрайтів): думає, радіє (успіх), чухає потилицю (помилка), бенкетує (кінець світу).

### Лис Микита: помічник і маскот

- **Образ — з казки Франка «Фарбований лис»** («Жив собі в однім лісі Лис Микита, хитрий-прехитрий»):
  лис, що впав у діжу з фарбою і став різнобарвним.
- **Колір змінюється залежно від локації** — ніби Микита щоразу вмочився в іншу фарбу
  (палітра — у LORE.md, §«Фарбований Микита»). Природний рудий колір — у його рідному Лісі.
- **Остромисл.** У казці пофарбований Микита назвався Остромислом. Це ім'я = «гострий розум»,
  тож воно стає його «режимом експерта» (напр. розширені пояснення після рішення).
- **Хвіст:** кінчик хвоста при анімації блимає як **курсор** `▌`.
- **Атрибут:** Книга хитрощів під пахвою; на палітурці — `{ }`.
- **Емоції:** хитро мружиться (успіх), підморгує (підказка), сміється з Вовка (оптимальне рішення).

### Персонажі інших творів

Лишаються у своїх світах як місцеві мешканці / NPC (Дидона в Карфагені, Харон у пеклі, звірі
в Рукавичці…). Між світами мандрують лише Еней, троянці та Лис Микита.

## 5. Світ: Ліс як мапа розділів

> ⚠️ **Застаріло (2026-10-15):** мапа тепер — мандрівка Енея світами різних творів, див. [`LORE.md`](LORE.md) §3. Локації нижче можна використати всередині світу Лиса Микити.

| Локація | Розділ / тема | Метафора |
|---|---|---|
| **Узлісся** | Онбординг, масиви, цикли | Перші кроки зі стежкою-масивом |
| **Стежка з двох кінців** | Two Pointers | Микита й Борсук ідуть назустріч |
| **Струмок** | Sliding Window | Рамка-сітка, що ковзає по струмку |
| **Ярмарок** | Hash Map / підрахунок | Прилавки, товар шукають за назвою миттєво |
| **Дупло** | Stack | Складаєш зверху, виймаєш зверху |
| **Мурашник** | Queue / BFS | Мурахи йдуть по черзі, хвилями |
| **Старий Дуб** | Trees | Буквально дерево: корінь, гілки, листки |
| **Павутина** | Graphs | Вузли й нитки між ними |
| **Бджолині соти** | Dynamic Programming | Таблиця-соти, кожна комірка спирається на сусідні |
| **Лабіринт нір** | Backtracking | Заліз у глухий кут, повернись і спробуй іншу нору |
| **Рукавичка** | Ємність, переповнення | Звірі набиваються, поки не лусне |
| **Царський двір** | Режим «співбесіда» / змагання | Фінальні задачі під таймер |

## 6. Ранги

У Франка Микита закінчує історію **канцлером** Царя Лева, тож це вершина рангів:

1. **Лисеня** — новачок
2. **Лис** — опанував базові хитрощі
3. **Хитрун** — впевнено розв'язує Easy
4. **Майстер хитрощів** — Medium
5. **Царський радник** — Hard
6. **Канцлер** — усі розділи, вершина

## 7. Візуальна ідентичність

**Стиль:** класичний піксель-арт (рішення 2026-10-15: без імітації вишивки й стібків).
Спрайти 16×16 – 32×32, чіткі квадратні пікселі. Українські орнаменти — як піксельні візерунки
(уламки Писанки, вишиванка Енея), рамки UI — орнаментальні смуги.

**Логотип (напрямки для ескізів):**
- **Основний (2026-10-15):** оселедець Енея у формі `{` + вордмарк «Кодеїда».
- A. Піксельна голова лиса; негативний простір морди утворює `</>`.
- B. Силует лиса, де вуха — `<` і `>`, а морда — `/`.
- C. Хвіст лиса, закручений у `{`, + вордмарк «Микита».

**Палітра (чорнова):**

## 8. Голос бренду

Іронічний, дотепний, як у Франка; трохи зухвалий, але **ніколи не принижує гравця**.
Жарти — на адресу Вовка, а не користувача. Мова за замовчуванням — українська, плюс англійська.

| Ситуація | Приклад |
|---|---|
| Успіх (оптимально) | «Цар задоволений! Вовк гризе лікті. 🦊» |
| Успіх, але повільно | «Працює, але так розв'язав би Вовк Неситий: O(n²). Пошукай хитрість.» |
| Time Limit | «Вовк не встиг, і ти теж. Може, є коротша стежка?» |
| Memory Limit | «Бурмило б позаздрив, скільки пам'яті ти зайняв.» |
| Помилка компіляції | «Микита спіткнувся на рядку 12: …» |
| Провалений edge case | «Кіт Мурко знову заліз у порожній масив. Перевір цей випадок.» |
| Підказка | Борсук: «Куме, а що як іти з обох кінців одночасно?» |
| Новий ранг | «Цар Лев жалує тобі звання Хитруна!» |
