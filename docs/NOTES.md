# Кодеїда — нотатки: ідея, рішення, план

> Стан на 2026-10-15: **пре-альфа**. Є сюжет, 16 світів, онбординг, персонажі, макет інтерфейсу і сайт
> ([f3an.github.io/kodeida](https://f3an.github.io/kodeida/)). Поточний код `app/` містить 44 вправи у світах 0–6;
> реліз містить світи 0–3 і мови TypeScript, JavaScript та Python. Інтерфейс українською й англійською, інсталятори для трьох ОС і автооновлення.
> Наступний крок — перший тест.
> Інші документи: [MVP.md](MVP.md) · [BRAND.md](BRAND.md) · [LORE.md](LORE.md) · [STORY.md](STORY.md) · [ONBOARDING.md](ONBOARDING.md).

## Ідея

Гейміфікована програма рівня Swift Playgrounds, яка вчить розв'язувати задачі рівня LeetCode / Codewars / HackerRank.

- **Ліворуч** — редактор у стилі VS Code (вкладки, умова, тести), **без AI-тулзів**.
- **Праворуч** — піксельний світ: код гравця керує героями (Еней і Лис Микита стають на вказівники, набирають воду,
  розплутують валку тощо).
- **Мета** — навчити *впізнавати потрібний прийом у задачі* і розуміти, чому він працює, а не просто здати задачу.
- Після кожного рішення — порівняння з рішенням **Вовка Неситого** (перебір), щоб складність O(n²) проти O(n) була наочною.

## Архітектура

Деталі й поточний стан — у [MVP.md](MVP.md).

```
┌──────────────── Electron window ────────────────┐
│  Ліва панель (Monaco)  │  Права панель (canvas)  │
│  - умова задачі        │  - світ, герої, NPC     │
│  - вибір мови          │  - програвання подій    │
│  - Запустити / Крок    │  - покроковий режим     │
│  - Суд богів (тести)   │  - порівняння з Вовком  │
└─────────────────────────────────────────────────┘
          │ код                     ▲ лог подій
          ▼                         │
   Web Worker (пісочниця, таймаут) ─┘
```

- **Раннер** — код гравця виконується в Web Worker з таймаутом: нескінченний цикл не вішає застосунок.
- **API світу** — лише в перших вправах світу 0 (`enei.move()`, `take()`, `jump()`, `fireAhead()`). Далі гравець пише
  звичайну функцію задачі, а світ спостерігає за читаннями масиву — тож навичка переноситься на LeetCode без перекладу.
- **Лог подій** — під час виконання збирається лог, права панель програє його як анімацію. Логіка однакова для всіх мов:
  для нової мови потрібен лише новий раннер.
- **Перевірка** — тести як на LeetCode + лічильник операцій (порівняння з Вовком, оцінка складності, зірки).
- **Прогрес** — зірки, уламки, вишиванка Енея, Книга хитрощів; зберігається локально.
- **Спільний рушій** — спрайти, заставки й мапа малюються кодом у `site/app.js`; гра бере їх командою
  `npm run sync-sprites`, тож сайт і гра виглядають однаково.
- **Оновлення** — `electron-updater` перевіряє GitHub Releases під час запуску, кожні 6 годин і з меню
  «Перевірити оновлення…»; завантажує у фоні, ставить після перезапуску.

4. ✅ **Python** (Pyodide), далі **усі 16 світів**, Книга хитрощів і вишиванка-прогрес.
5. **C#, C++, Go**, далі нові кампанії.
6. **Гранти й спільнота** — заявки на гранти (УКФ, edtech-програми), шаблон issue «World idea» для нових світів.

## Ризики

- **Обсяг.** 16 світів, ~70 вправ, кілька мов — дуже багато для одного автора; MVP треба тримати маленьким.
- **Код → анімація.** Найскладніша технічна частина: інструментування коду або API світу, яке не підміняє навичку.
- **Кілька мов офлайн.** JS/TS — просто, Python — Pyodide (~10 МБ), C#/C++/Go в Electron — окремий проєкт.
- **Аудиторія.** Сюжет і піксель-арт тягнуть до підлітків, задачі — до тих, хто готується до співбесід. Основна
  аудиторія — студенти й джуни, які бояться алгоритмів.
