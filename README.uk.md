**Гра, де твій код рухає героя.** Разом з Енеєм і Лисом Микитою ти вивчаєш прийоми задач рівня LeetCode — два вказівники, хеш-мапи, графи, динамічне програмування — у світах української літератури. Без AI-підказок: код пишеш ти, а світ виконує його крок за кроком.

## Ідея

Більшість застосунків дають задачі. Кодеїда вчить **бачити в задачі прийом** і розуміти, чому він працює.

- **Хитрощі, а не відповіді.** Кожен світ — один прийом. Підвідні вправи ведуть до справжньої задачі.
- **Видно, як працює код.** Ліворуч редактор у стилі VS Code, праворуч піксельний світ, що виконує код рядок за рядком.
- **Вовк проти Микити.** Після кожного рішення видно, скільки кроків зробив би перебір.
- **Українська класика.** Рамка — «Енеїда» Котляревського: Юнона розбила Кришталеву Писанку, уламки розлетілися по інших книжках, і Еней пливе світ за світом, щоб їх зібрати.

Мови: спершу TypeScript і JavaScript, далі Python, потім C#, C++ і Go. Сама гра буде офлайн-застосунком для комп'ютера (Electron).

## Стан

**Пре-альфа.** Готові сюжет, 16 світів із задачами, онбординг на 13 сцен, персонажі, макет інтерфейсу й сайт. У застосунку (`app/`) є перший рівень, у який можна грати: «Задача Дидони» (*Container With Most Water*) з пісочницею, анімованим світом, тестами й порівнянням з Вовком. Технічний план — у [docs/MVP.md](docs/MVP.md).

## Що в репозиторії

- `app/` — гра: Electron + React + TypeScript + Monaco.
- `site/` — сайт (лендінг і артбук), деплоїться на GitHub Pages.
- `docs/` — дизайн-документи: ідея й план (`NOTES.md`), технічний план MVP (`MVP.md`), бренд (`BRAND.md`), лор (`LORE.md`), сюжет (`STORY.md`), сценарій вступу (`ONBOARDING.md`).

Запустити гру (потрібен Node.js 22+):

```bash
cd app
npm install
npm run dev      # у браузері: http://localhost:5173
npm start        # зібрати й відкрити застосунок Electron
```

Запустити сайт локально:

```bash
cd site
python3 -m http.server 8000
```
