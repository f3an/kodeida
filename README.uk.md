**Гра, де твій код рухає героя.** Разом з Енеєм і Лисом Микитою ти вивчаєш прийоми задач рівня LeetCode — два вказівники, хеш-мапи, графи, динамічне програмування — у світах української літератури. Без AI-підказок: код пишеш ти, а світ виконує його крок за кроком.

**[f3an.github.io/kodeida →](https://f3an.github.io/kodeida/)** · [Артбук](https://f3an.github.io/kodeida/artbook.html) · [English](README.md)

## Ідея

Більшість застосунків дають задачі. Кодеїда вчить **бачити в задачі прийом** і розуміти, чому він працює.

- **Хитрощі, а не відповіді.** Кожен світ — один прийом. Підвідні вправи ведуть до справжньої задачі.
- **Видно, як працює код.** Ліворуч редактор у стилі VS Code, праворуч піксельний світ, що виконує код рядок за рядком.
- **Вовк проти Микити.** Після кожного рішення видно, скільки кроків зробив би перебір.
- **Українська класика.** Рамка — «Енеїда» Котляревського: Юнона розбила Кришталеву Писанку, уламки розлетілися по інших книжках, і Еней пливе світ за світом, щоб їх зібрати.

Мови коду: зараз TypeScript і JavaScript, далі Python, потім C#, C++ і Go. Гра — офлайн-застосунок для macOS, Windows і Linux (Electron), українською й англійською.

## Стан

**Пре-альфа.** Готові сюжет, 16 світів із задачами, онбординг на 14 сцен, персонажі, макет інтерфейсу й сайт. У застосунку (`app/`) готовий вміст MVP: онбординг з персонажами, що говорять, і туром Сивілли, світи 0–2 (16 вправ, від першого `enei.move()` до *Container With Most Water*) з пісочницею, анімованим світом, тестами й порівнянням з Вовком, українською й англійською. Інсталятори для трьох систем збираються з кожного тегу релізу, а встановлена гра оновлюється сама з GitHub Releases. Технічний план — у [docs/MVP.md](docs/MVP.md).

## Завантажити

Інсталятори — на [сторінці релізів](https://github.com/f3an/kodeida/releases): `.dmg` для macOS, `Kodeida-Setup-….exe` для Windows, `.AppImage` для Linux. Гра перевіряє оновлення під час запуску й кожні 6 годин (а також **Kodeida → Перевірити оновлення…** у меню, кнопка в головному меню і **Налаштування → Оновлення**), завантажує їх у фоні й ставить після перезапуску.

## Що в репозиторії

- `app/` — гра: Electron + React + TypeScript + Monaco. Спрайти, сцени й мапа беруться з `site/app.js` командою `npm run sync-sprites`.
- `site/` — сайт (лендінг і артбук, обидва українською й англійською), деплоїться на GitHub Pages.
- `docs/` — дизайн-документи: ідея й план (`NOTES.md`), технічний план MVP (`MVP.md`), бренд (`BRAND.md`), лор (`LORE.md`), сюжет (`STORY.md`), сценарій вступу (`ONBOARDING.md`).

Запустити гру (потрібен Node.js 22+):

```bash
cd app
npm install
npm run dev            # у браузері: http://localhost:5173
npm start              # зібрати й відкрити застосунок Electron
npm run selftest       # перевірка рушія й кожної вправи без браузера
npm run dist           # інсталятор для поточної системи в app/release/
KODEIDA_USER_DATA=/tmp/kd npm start   # з чистим профілем: онбординг з нуля
```

Реліз: підняти версію в `app/package.json` і запушити тег `vX.Y.Z` — див. [CONTRIBUTING.md](CONTRIBUTING.md#releases).

Запустити сайт локально:

```bash
cd site
python3 -m http.server 8000
```
