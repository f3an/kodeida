## Як це виглядає

**Розв'язуєш справжню задачу й бачиш кожен крок.** Задача Дидони — це LeetCode 11, *Container With Most Water*. «Запустити» показує, як два вказівники йдуть назустріч уздовж стовпів. «Суд богів» проганяє приховані тести, зокрема на 10 000 стовпів, і порівнює твій код з перебором Вовка.

<p align="center"><img src="docs/media/play-uk.gif" width="860" alt="Екран рівня: рішення maxArea в редакторі, Еней і Микита ведуть два вказівники вздовж стовпів у Карфагені, далі всі тести пройдено, а код дивиться на дані в 2500 разів рідше, ніж Вовк"></p>

**Історія починається на Олімпі.** Боги бенкетують біля Кришталевої Писанки, доки Юнона й Еол її не розбивають, і уламки розлітаються по книжках української літератури. Усі персонажі говорять: десять заставок підводять до перших рядків коду.

<p align="center"><img src="docs/media/intro-uk.gif" width="760" alt="Вступні заставки: бенкет богів на Олімпі, змова Юнони з Еолом, буря розбиває Писанку й уламки летять у книжки, Венера просить Зевса про допомогу"></p>

**Шістнадцять світів, шість пісень.** Кожен світ — один прийом, від масивів і двох вказівників до графів і динамічного програмування. Уже можна пройти дев'ять: світи 0–8.

<p align="center"><img src="docs/media/map-uk.gif" width="680" alt="Мапа світів: острови-пісні, кораблик пливе від світу до світу, а картка показує сцену світу, прийом і задачу з LeetCode"></p>

**Ще не пишеш код? Почни з Абетки.** Меню питає, чи вмієш ти програмувати. «З нуля» відкриває Абетку: Сивілла вчить Енея на українських казках у ніч перед падінням Трої — Python, JavaScript чи TypeScript, — а кожен виведений рядок з'являється на сувої.

## Ідея

Більшість сайтів дають задачі. Кодеїда вчить **бачити в задачі прийом** і розуміти, чому він працює.

- **Хитрощі, а не відповіді.** Кожен світ — один прийом. Підвідні вправи ведуть до справжньої задачі: *Container With Most Water*, *Top K Frequent Elements*, *Linked List Cycle*, …
- **Видно, як працює код.** Ліворуч редактор у стилі VS Code, праворуч піксельний світ, що відтворює твій код крок за кроком.
- **Вовк проти Микити.** Після кожного рішення видно, скільки разів перебір подивився б на дані. O(n²) проти O(n) стає видимим.
- **Українська класика.** Рамка — «Енеїда» Котляревського. Еней пливе з книжки в книжку, щоб зібрати уламки Писанки: Франків Лис Микита, «Рукавичка», «Лісова пісня» Лесі Українки, Карпати Коцюбинського, «Конотопська відьма» Квітки-Основ'яненка.

Мови коду: зараз TypeScript, JavaScript і Python (через Pyodide, вбудований, працює без інтернету), потім C#, C++ і Go. Інтерфейс українською й англійською. Гра працює без інтернету.

## Три шляхи

Новий гравець у головному меню відповідає на одне питання: **чи вмієш ти програмувати?**

| Відповідь | Куди веде |
|---|---|
| 🌱 **Ні, з нуля** | **Абетка** — окрема доріжка для дорослих, які вчать першу мову. Обираєш Python, JavaScript чи TypeScript: кожен урок написано саме для цієї мови, а те, що виводить програма, рядок за рядком з'являється на сувої. Сивілла вчить Енея на українських казках у ніч перед падінням Трої; після Абетки сюжет іде далі, до світу 0. |
| 🧭 **Трохи вмію** | Вступ і світ 0 «Попелище Трої»: одна нова ідея на вправу — команда, цикл, умова, лічильник. |
| ⚔️ **Так, хочу задач** | Вступ, а тоді одразу світ 1 «Море Еола». Світ 0 лишається відкритим для повторення. |

Хоч яким шляхом підеш, на першій вправі Сивілла покаже, як влаштований інтерфейс. «Змінити рівень» у меню знову відкриває вибір, а прогрес не губиться; Абетка завжди під рукою в бічній панелі.

## Стан

**Пре-альфа, готова до першого тесту.**

- **Можна пройти (v0.5.0):** вступ (10 заставок, перший запуск у справжньому редакторі, тур Сивілли) і світи 0–8. Це 54 вправи: від першого `enei.move()` до *Combination Sum* у пеклі, з тестами, підказками, зірками й порівнянням з Вовком. Між світами — заставки-переходи. Умови написано так, щоб їх зрозумів і п'ятнадцятирічний: нові терміни пояснено, є розібраний приклад, без обмежень на кшталт 10⁴.
- **Абетка:** усі вісім розділів, по 4 уроки для Python, JavaScript і TypeScript: «Колобок» (вивід), «Ріпка» (змінні й числа), «Котигорошко» (рядки), «Коза-дереза» (умови), «Солом'яний бичок» (цикли), «Пан Коцький» (списки), «Лисичка-сестричка» (словники й об'єкти), «Івасик-Телесик» (функції). Розділи 2–8 вийшли у v0.4.0.
- **Новий вигляд (v0.5.0):** усіх героїв, світи й заставки вступу перемальовано: 33 живі фони зі сяйвом, водою, димом і снігом, анімовані заставки (бенкет богів, вітри Еола, розлам Писанки), свій фон для кожної казки Абетки, де герої виходять на сцену разом із виводом програми, і Еней у жупані в холодних світах.
- **Придумано:** увесь сюжет, 16 світів із прийомами, персонажі й піксель-арт, бренд. Усе це є в [артбуці](https://f3an.github.io/kodeida/artbook.html).
- **Випущено:** інсталятори для macOS, Windows і Linux з кожного тегу релізу, автооновлення з GitHub Releases.

Технічний план — у [docs/MVP.md](docs/MVP.md).

## Тестування

Шукаємо 10–20 людей, насамперед студентів і джунів, які бояться алгоритмів. Головне питання тесту: **чи розв'яжеш після світу 2 справжню [Container With Most Water](https://leetcode.com/problems/container-with-most-water/) на LeetCode без гри?**

1. Встанови [останній реліз](https://github.com/f3an/kodeida/releases/latest) і пройди до Задачі Дидони включно.
2. Натисни **Залишити відгук** у головному меню, налаштуваннях чи в меню «Довідка» або **Розкажи, як пройшло** після Задачі Дидони. Відкриється [коротка форма](https://github.com/f3an/kodeida/issues/new?template=playtest.yml) з уже заповненими версією, системою й прогресом. Потрібен акаунт GitHub.

## Як це працює

- **Твій код — звичайний код.** Рівень — це підпис з LeetCode, наприклад `maxArea(height: number[]): number`. Ігрового API, яке думало б замість тебе, немає.
- **Світ стежить, що ти читаєш.** Масиви й рядки загорнуті в `Proxy`, який записує кожне читання й запис. Ці події анімує сцена, а їх кількість ми порівнюємо з Вовком.
- **Пісочниця з тайм-аутом.** Код виконується у Web Worker. Нескінченний цикл зупиняє прогін, а не гру.
- **Суд богів.** Приклади, приховані тести й один великий тест (наприклад, на 10 000 елементів) визначають вердикт: по-лисячому, по-вовчому (правильно, але повільно), неправильна відповідь, час вийшов або помилка на рядку N.
- **Піксель-арт.** Герої, фони й анімації — PNG-спрайти в [`app/src/assets/art`](app/src/assets/art), намальовані ×2 на дрібній сітці без згладжування. Їх зроблено генератором [PixelLab](https://www.pixellab.ai) і доопрацьовано вручну (обличчя, голови між кадрами, прибрані артефакти). Сяйво, воду, дим і сніг поверх малює код ([`bgfx.ts`](app/src/world/bgfx.ts)). Перша версія арту, повністю з фігур у [`site/app.js`](site/app.js), і далі малює мапу, інтерфейс і все, для чого ще немає нового спрайта.

## Розробка

Потрібен Node.js 22 або новіший.

```bash
cd app
npm install
npm run dev            # у браузері: http://localhost:5173
npm start              # зібрати й відкрити застосунок Electron
npm run selftest       # рушій і кожна вправа, без браузера
npm run typecheck
npm run sync-sprites   # скопіювати спрайти, сцени й мапу з site/app.js
npm run dist           # інсталятор для поточної системи в app/release/
```

Змінні середовища: `KODEIDA_USER_DATA=/tmp/kd` — чистий профіль (вступ з нуля); `KODEIDA_SMOKE=1` — смоук-тест і вихід; `KODEIDA_SMOKE=update` — перевірка оновлень у зібраному застосунку.

Сайт збирати не треба:

```bash
cd site
python3 -m http.server 8000   # http://localhost:8000 і /artbook.html
```

Трейлер, ролик до релізу й Reels збираються в `video/` на [Remotion](https://www.remotion.dev). Вони використовують арт самої гри (`npm run art` копіює його в `public/art`), а музику синтезує скрипт:

```bash
cd video
npm install
npm run sfx                            # звукові ефекти → public/
npm run music                          # музика трейлера й ролика до релізу
npm run art                            # арт гри й рендери сайту → public/art
npm run record                         # кадри гри у 2× (потрібна запущена гра, див. CONTRIBUTING)
npm run dev                            # Remotion Studio: перегляд і правки
npx remotion render Trailer-uk out/kodeida-trailer-uk.mp4
```

Як стиснути трейлер для сайту й зробити обкладинку Reels — у [CONTRIBUTING.md](CONTRIBUTING.md#trailer-and-videos).

## Долучитися

Зараз особливо потрібні ідеї світів, арт, сюжет, переклади й відгуки про доступність. Застосунок молодий і швидко змінюється, тож щодо коду спершу відкрийте issue, щоб домовитися про підхід.
